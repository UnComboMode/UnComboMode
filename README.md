## Hey there, I'm UnComboMode 👋

Building in public, learning out loud.

I build and maintain cloud infrastructure, mostly on Linux, using Terraform and Kubernetes to keep things reproducible and scalable. I care about automation that actually reduces toil, not just automation for its own sake.
